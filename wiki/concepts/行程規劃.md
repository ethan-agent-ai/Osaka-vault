# 大阪行程規劃

## 經典 3 日路線

### Day 1：南部（難波・道頓堀・心齋橋）
- 上午：抵達難波 → [[wiki/entities/區域/難波]] 高島屋開逛
- 中午：[[wiki/entities/餐廳/Dorajyu]] 御好燒
- 下午：心齋橋筋 → [[wiki/entities/購物/心齋橋PARCO]]
- 晚上：道頓堀夜景 + [[wiki/entities/餐廳/馬鹿一代噴火拉麵]]

### Day 2：北部（梅田 + 港區）
- 上午：[[wiki/entities/區域/梅田]] 早餐 → LUCUA 購物
- 中午：[[wiki/entities/餐廳/Gyukatsu-Motomura-LUCUA]]
- 下午：[[wiki/entities/景點/海遊館]] + 天保山摩天輪
- 晚上：梅田夜景 + 燒肉

### Day 3：天王寺 + 動物園 + 展望台
- 上午：[[wiki/entities/景點/大阪市天王寺動物園]]
- 中午：新世界 [[wiki/entities/餐廳/餐廳總覽]]
- 下午：[[wiki/entities/景點/Harukas300展望台]]
- 晚上：難波高島屋掃伴手禮 → 機場

## 5 日延伸
